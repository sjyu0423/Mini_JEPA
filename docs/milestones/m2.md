# Milestone 2: What did Mini-JEPA learn?

## Research questions

M2 evaluates the unchanged epoch-5 M1 checkpoint. The questions are:

1. Is the low raw predictor variance evidence of collapse or primarily an embedding-scale effect?
2. Can frozen context, predicted-future, and actual-target embeddings support physical-state probes?
3. Does JEPA pretraining improve position decodability over the same randomly initialized frozen
   architecture?
4. How does a frozen JEPA probe compare with labeled image prediction and position-aware physics
   baselines, including bounce events and higher-speed out-of-distribution motion?

No JEPA parameters were updated and the M1 checkpoint was not modified.

## Data and experimental protocol

The in-distribution data is exactly the M1 corpus generated with seed 2026 and speeds 0.25–0.65:

| Split | Trajectories | Four-frame windows | Use |
| --- | ---: | ---: | --- |
| Train | 256 | 7,168 | Probe and supervised-baseline fitting |
| Validation | 64 | 1,792 | Epoch selection and representation diagnostics |
| Test | 32 | 896 | One final held-out comparison |

The test set contains 20 horizon-1 bounce windows and 876 non-bounce windows. Uncertainty intervals
bootstrap complete trajectories rather than overlapping windows.

A disjoint OOD test corpus was generated with seed 9090, 64 trajectories, and speeds 0.8–1.2. It
contains 1,792 windows, including 81 bounce windows. No probe, JEPA component, or supervised model
was trained on OOD trajectories. Different random seeds provide unseen initial positions and
directions in both test sets. Only horizon 1 is evaluated because M1 trained only a horizon-1
checkpoint; no horizon-1 model is silently reused as a different-horizon model.

## Models, supervision, and input access

The comparisons intentionally have different access and should not be interpreted as identical
learning setups:

- **Constant velocity:** receives measured positions from the last two observed frames and
  extrapolates their displacement. It has privileged coordinates unavailable to JEPA.
- **Wall-aware velocity:** uses the same measured positions and folds extrapolated coordinates
  through the known elastic arena bounds. It has both privileged coordinates and correct physics.
- **Supervised CNN:** receives the same four images as JEPA but is trained end-to-end on 7,168
  labeled future-position windows. It has 146,770 trainable parameters.
- **JEPA + frozen probe:** receives predicted embeddings from the fully frozen M1 context encoder
  and predictor. Only a two-layer `64 -> 64 -> 2` position probe is trained with labels.
- **Random frozen + probe:** uses the same frozen JEPA architecture and same probe protocol, but
  all representation weights are randomly initialized. This isolates the value of M1 pretraining.
- **Target-embedding probe:** uses the actual future image's frozen EMA target embedding. It is an
  information diagnostic, not a deployable future predictor.

Ground-truth state is used only as probe/baseline supervision and evaluation labels. The frozen
JEPA predictor receives only `(batch, 4, 1, 64, 64)` observations. Extraction computes context and
prediction before separately encoding the future target image, and automated tests verify that
changing the future image cannot change a prediction.

## Frozen probe results

Three independent probes were fitted on training embeddings and selected on validation data:

- current context to last-observed position and velocity;
- predicted future embedding to future position;
- actual target embedding to actual target position.

On the held-out test set, the current-state probe obtained 3.408 px position RMSE and 0.310
physical-units/second velocity-vector RMSE. The predicted-future probe obtained 2.835 px position
RMSE. The actual-target embedding probe obtained 1.852 px RMSE. Thus both representation branches
contain decodable position information, while the predictor loses some of the position information
available in the target representation.

## Held-out position comparison

Coordinates are converted with 63 pixels per unit, matching the renderer's center-coordinate map.
MAE is mean absolute coordinate error; the remaining distribution statistics use Euclidean error.

| Model | MAE px | Euclidean RMSE px | Median px | P90 px | Bounce mean px | Non-bounce mean px |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Constant velocity | 0.019 | 0.215 | 0.000004 | 0.000005 | 0.793 | 0.020 |
| Wall-aware velocity | 0.007 | 0.111 | 0.000004 | 0.000005 | 0.000002 | 0.014 |
| Supervised CNN | 0.346 | 0.650 | 0.453 | 1.008 | 0.782 | 0.539 |
| JEPA + frozen probe | 1.542 | 2.835 | 2.129 | 4.156 | 3.466 | 2.383 |
| Random frozen + probe | 6.230 | 11.394 | 8.780 | 17.395 | 10.782 | 9.738 |

The trajectory-bootstrap mean-error interval is 2.171–2.677 px for JEPA + probe, compared with
0.499–0.598 px for the supervised CNN. Only 20 test windows contain a bounce, so the bounce subset
is informative but small. The wall-aware baseline is nearly exact on bounce windows because it is
given measured positions and the correct arena law. Its few non-bounce errors occur primarily when
the displacement-estimation interval itself straddles a preceding collision.

M1 pretraining clearly improves fixed-protocol probe performance over random weights, but the
learned representation remains substantially less position-accurate than direct labeled training.

## Prediction-variance investigation

M1 logged variance as the average of per-batch population variances. M2 computes global validation
population variance for each coordinate, so the raw values are slightly larger. The conclusions do
not depend on that aggregation difference.

| Diagnostic | Context | Prediction | Target |
| --- | ---: | ---: | ---: |
| Mean raw per-dimension variance | 0.5099 | 0.01646 | 0.7619 |
| Mean L2 norm | 7.9918 | 1.1590 | 7.9757 |
| Mean variance after per-sample unit normalization | 0.00798 | 0.01190 | 0.01198 |
| Different-sample cosine mean | 0.4919 | 0.2364 | 0.2352 |
| Covariance effective rank (maximum 64) | 21.35 | 21.82 | 23.14 |
| Participation ratio | 15.18 | 16.69 | 17.25 |
| Top-five covariance fraction | 0.468 | 0.442 | 0.425 |

Predictions have much smaller raw magnitude than targets because cosine loss is scale-invariant.
After unit normalization, prediction and target variance are almost identical, their different-
sample cosine statistics match, and their covariance ranks are close. Therefore the M1 raw
variance gap is predominantly a **normalization/scale artifact**, not total or low-rank collapse.

Correct prediction-target cosine similarity is 0.9808, versus 0.2200 for deterministically
mismatched targets. The mean margin is 0.7608, and the correct pair exceeds the mismatch in 99.94%
of validation samples. Predictions are diverse and sample-specific. Nevertheless, the worse future
probe compared with the target probe shows a real reduction in position-decodable information; the
absence of collapse is not the same as complete information preservation.

## Higher-speed generalization

| Model | ID RMSE px | High-speed OOD RMSE px | OOD bounce mean px | OOD non-bounce mean px |
| --- | ---: | ---: | ---: | ---: |
| Constant velocity | 0.215 | 0.596 | 1.602 | 0.083 |
| Wall-aware velocity | 0.111 | 0.312 | 0.044 | 0.058 |
| Supervised CNN | 0.650 | 1.247 | 1.202 | 1.039 |
| JEPA + frozen probe | 2.835 | 5.391 | 4.995 | 4.567 |
| Random frozen + probe | 11.394 | 12.408 | 14.175 | 10.536 |

All learned models degrade as velocity moves outside the M1 training range. JEPA's error nearly
doubles and remains much worse than supervised coordinate prediction. The pretraining advantage
over random features persists, but generalization is limited.

## Limitations and M3 recommendation

- The probe is nonlinear, so results establish decodability by a small MLP rather than strictly
  linear separability.
- All selected probe and supervised runs reached their fixed epoch budgets; a larger validation-
  only tuning study might improve them, but was intentionally excluded from this bounded milestone.
- Bounce uncertainty is high because the in-distribution test split has only 20 bounce windows.
- Random-feature performance depends on one fixed seed; multiple random initializations would
  strengthen the pretraining comparison.
- The actual-target probe sees the future image and must not be compared as a deployable predictor.
- The evaluation covers a single ball, arena, image style, and a single trained horizon.

For M3, retain the current results as the baseline and focus on why target position is only
partially preserved through the predictor. Recommended experiments are scale-aware or normalized
predictor objectives, horizon-conditioned training, stronger temporal aggregation, and multiple
random seeds. Any architectural change should create a new training run and be compared against
this frozen M1 checkpoint; the M2 evaluation code should remain unchanged as much as possible.
