# Milestone 3: Controlled model-improvement experiments

## Hypotheses and protocol

M3 tested three hypotheses without modifying any M1/M2 checkpoint:

1. A recurrent temporal aggregator may encode motion better than concatenation plus an MLP.
2. Explicit normalized-vector regression may retain more useful state than cosine prediction.
3. Predicting offsets 1, 2, and 4 jointly may encourage a better motion representation.

Every run records a canonical JSON configuration, model parameter count, epoch metrics, best
checkpoint, validation probes, and representation diagnostics. All runs used the M1 data generated
with seed 2026, four observed frames, 64-dimensional embeddings, hidden size 128, AdamW, learning
rate `3e-4`, weight decay `1e-4`, EMA `0.99`, batch size 64, five epochs, and the same 120-epoch
frozen-probe protocol.

Stage 1 used training seed 310 and selected the non-baseline family with the lowest horizon-1
validation frozen-probe RMSE. No held-out or diagnostic data was used. Stage 2 then trained the
original family and selected family with seeds 501, 502, and 503. Held-out test, high-speed OOD,
and independent bounce diagnostics were evaluated only after this family selection was fixed.

## Architecture and objective variants

The frame CNN and EMA target encoder remain unchanged.

- **Temporal MLP:** concatenates four 64-dimensional frame vectors and maps `256 -> 128 -> 64`.
- **Temporal GRU:** feeds the frame vectors in temporal order through a 128-state GRU and projects
  the final hidden state to 64 dimensions. This adds 41,600 trainable parameters.
- **Cosine:** the original `1 - cosine(prediction, target)` objective plus variance regularization.
- **Normalized regression:** unit-normalizes prediction and target and applies scaled Smooth-L1
  regression, retaining the same variance regularization.
- **Multi-horizon:** uses a learned horizon embedding and conditioned predictor for offsets 1, 2,
  and 4. The context always contains only the same four observed frames.

## Stage-1 validation experiments

| ID | Architecture | Objective | Horizons | Parameters | Best latent val. loss | H1 probe RMSE px |
| --- | --- | --- | --- | ---: | ---: | ---: |
| A0 | Temporal MLP | Cosine | 1 | 203,584 | 0.01735 | 3.355 |
| A1 | GRU | Cosine | 1 | 245,184 | 0.01677 | **3.051** |
| B0 | Temporal MLP | Normalized regression | 1 | 203,584 | 0.01735 | 3.355 |
| C1 | GRU + conditioned predictor | Normalized regression | 1, 2, 4 | 253,696 | 0.04362 | 3.219 |

A1 was selected using horizon-1 validation probe RMSE.

### Objective result

B0 reproduced A0 almost exactly: their latent curves, validation probe RMSE, embedding variance,
rank, and cosine statistics differ only at floating-point noise. During this run all normalized
coordinate residuals stayed in Smooth-L1's quadratic region. The implemented
`64 * mean(smooth_l1)` therefore reduced to one half of the squared distance between unit vectors,
which is the same geometry as cosine distance. This is a valid negative result: the attempted
objective was not materially distinct in the observed regime and did not improve representation
quality. A future scale-sensitive objective must add information not removed by normalization.

### Multi-horizon result

C1 validation probe RMSE was 3.219 px at horizon 1, 3.211 px at horizon 2, and 4.758 px at horizon
4. Joint training did not beat the single-horizon GRU at horizon 1, so C1 was not selected and was
not evaluated on the held-out test. This preserves the rule that test data is used only for
validation-selected families.

## Stage-2 seed variability

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A0 MLP + cosine | 3.030 ± 0.372 | 2.353 ± 0.274 | 4.628 ± 0.623 | 3.946 ± 1.071 | 2.592 ± 0.279 | 5.075 ± 0.521 |
| A1 GRU + cosine | **2.894 ± 0.217** | **2.236 ± 0.116** | **4.305 ± 0.414** | **3.881 ± 0.749** | **2.467 ± 0.168** | **3.884 ± 0.292** |

Values are sample mean ± sample standard deviation over seeds 501, 502, and 503. The GRU reduces
mean test RMSE by 4.5% relative to the retrained A0 family and reduces mean high-speed OOD RMSE by

The historical unchanged M1/M2 point estimate is 2.835 px ID and 5.391 px OOD. The GRU family mean
does **not** beat M1 on ID error, though it is much better on OOD error. Direct comparison to one M1
seed must be cautious because M1 has no three-seed estimate.

## Selected checkpoint

Within the validation-selected A1 family, seed 502 had the best Stage-2 validation RMSE (2.918 px)
and is the named checkpoint:

```text
artifacts/m3/stage2/a1_gru_cosine/seed-502/best.pt
```

It obtained:

- held-out RMSE: 2.694 px;
- held-out median / P90: 2.115 / 4.064 px;
- held-out bounce / non-bounce mean error: 3.431 / 2.304 px;
- high-speed OOD RMSE: 3.578 px;
- high-speed bounce / non-bounce mean error: 3.460 / 3.127 px.

This single selected seed beats the historical M1 point estimate by 5.0% ID and 33.6% OOD, but the
seed-averaged ID result does not. The defensible conclusion is improved OOD robustness with only a
small, uncertain ID improvement.

## Independent bounce-rich diagnostics

The diagnostic dataset uses seed 12,345 and contains 64 complete trajectories per condition. Each
condition contributes 1,792 windows and is never used for training or selection.

| Condition | Bounce windows | M1 RMSE px | M3 RMSE px | M1 bounce mean px | M3 bounce mean px |
| --- | ---: | ---: | ---: | ---: | ---: |
| Ordinary | 39 | 3.072 | **2.841** | **4.104** | 4.618 |
| Near-wall | 48 | 3.456 | **2.715** | **3.131** | 3.487 |
| Multiple-bounce | 249 | 14.241 | **7.745** | 11.681 | **5.912** |
| High-speed OOD | 93 | 5.682 | **3.675** | 4.906 | **4.136** |

The selected GRU improves full-condition RMSE in all four conditions and sharply improves
multiple-bounce/high-speed behavior. Bounce-only improvement is not consistent: ordinary and
near-wall bounce means are slightly worse than M1. Across all 7,168 diagnostic windows, M3 RMSE is
4.715 px; its 429 bounce windows have 5.138 px mean error versus 3.669 px for non-bounces.

## Limitations and recommendation

- Five epochs constrain every run equally but may not be optimal for GRU or multi-horizon models.
- Stage 2 covers three seeds, while the historical M1 result covers one.
- The selected nonlinear probes all use a fixed optimization budget and reached that budget.
- The multi-horizon experiment changes both predictor form and available window count, so it is a
  controlled practical comparison rather than a perfect single-factor ablation.
- Ordinary and near-wall bounce-only results did not improve, despite better overall condition
  RMSE.
- Physics-aware and supervised M2 baselines remain far more accurate than JEPA probes.

The next milestone should retain A1 seed 502 as an OOD-robust candidate but should not claim a
decisive in-distribution breakthrough. Recommended work is a genuinely scale-sensitive latent
objective, balanced or event-aware training that increases bounce coverage without leaking labels
into JEPA inputs, longer-horizon validation across several seeds, and direct comparison of probe
sample efficiency. Any new claims should continue using the untouched M1 and M3 three-seed results
as fixed references.
